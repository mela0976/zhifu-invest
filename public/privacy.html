隱私權政策草案

只蒐集完成會員、資格與服務流程必要的資料。

蒐集資料使用目的LINE 與分析會員權利
待法律審閱｜營運主體、聯絡窗口、保存年限與跨境處理資訊須在正式上線前補齊。

可能蒐集的資料

會員啟用時可能蒐集 LINE userId、顯示名稱、真實姓名、手機、Email、社群來源碼、官方帳號好友狀態及同意紀錄。資格流程僅保存狀態、審核機構、審核人、日期、參考編號與有效期限；第一版不在平台上傳身分證或財力證明。

認購作業保存專案、申請／核准／入金／分配／退款金額、各流程狀態、時間、操作者與更正原因。這些紀錄不會公開，也不會顯示給其他會員。

處理目的與權限

  • 驗證社群來源與啟用會員服務。
  • 依資格與專案白名單控制資料室存取。
  • 記錄認購意向及站外核准、入金與分配結果。
  • 發送必要狀態通知、處理顧問預約及建立稽核歷程。

引薦人可操作營運後台；涉及資格或受監管內容時，仍須保存合作方站外核准證據。技術管理權不等於合規核准權。

LINE 與網站分析

LINE Login 與 Messaging API Channel 應置於同一 Provider。必要交易通知只提示狀態更新，不在 LINE 訊息顯示認購或財務金額。行銷通知使用獨立同意，可隨時取消。

GA4 僅可記錄不含個資的頁面與轉換事件；姓名、手機、Email、LINE userId、會員編號及任何認購金額不得傳送至分析工具。

查詢、更正與停用

會員可要求查詢或更正個人資料、停止非必要行銷通知或停用帳戶。帳戶停用後，非必要個資將依正式政策刪除或去識別；依法或依合作方規則須保存的認購與稽核紀錄將封存，而不是直接硬刪除。
